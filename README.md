## 🚀 Como Usar

Copie qualquer snippet das seções abaixo e cole direto no seu `README.md`.

```md
<!-- GIF básico -->
![Codando](https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif)

<!-- Centralizado com HTML -->
<div align="center">
  <img src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" width="300"/>
</div>

<!-- Badge de tecnologia -->
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
```

> 💡 **Dica:** Use `width` para controlar o tamanho e `align="center"` para centralizar na página.

## 🛠️ Ferramentas para criar seu README

> As melhores ferramentas para montar, estilizar e turbinar o seu README.

<div align="center">

| Ferramenta | O que faz | Link |
|-----------|-----------|------|
| 🧙 **readme.so** | Editor visual de README com arrastar e soltar | [readme.so](https://readme.so) |
| ⚡ **Profile README Generator** | Gera README de perfil GitHub com formulário | [rahuldkjain.github.io](https://rahuldkjain.github.io/gh-profile-readme-generator) |
| 🎨 **Shields.io** | Cria badges/ícones personalizados infinitos | [shields.io](https://shields.io) |
| 🌊 **Skill Icons** | Ícones de tecnologias prontos e bonitos | [skillicons.dev](https://skillicons.dev) |
| 📊 **GitHub Stats** | Cards de estatísticas do GitHub para o perfil | [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) |
| 🐍 **Contribution Snake** | Animação de cobrinha comendo seus commits | [platane/snk](https://github.com/platane/snk) |
| 🔥 **GitHub Streak Stats** | Card com sua sequência de contribuições | [streak-stats](https://github-readme-streak-stats.herokuapp.com) |
| 🏆 **GitHub Profile Trophy** | Troféus baseados nas suas métricas do GitHub | [ryo-ma/github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) |
| 🎵 **Spotify Now Playing** | Mostra a música que você está ouvindo | [novatorem](https://github.com/novatorem/novatorem) |
| 📈 **Wakatime Stats** | Exibe quanto tempo você codou por linguagem | [wakatime.com](https://wakatime.com) |
| 🖼️ **Capsule Render** | Cabeçalhos e rodapés animados e coloridos | [capsule-render](https://github.com/kyechan99/capsule-render) |
| 🃏 **Typing SVG** | Texto animado de digitação para o README | [readme-typing-svg](https://readme-typing-svg.demolab.com) |

</div>
